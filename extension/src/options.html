Amy Brain Map 연결

이 Chrome 프로필의 탐색 흔적을 나의 지도에 연결합니다.

연결 순서

  1. 1
    웹 대시보드에서 연결 코드 발급Amy Brain Map에 Google 로그인한 뒤, Chrome 기록 연결 카드에서 연결 코드를 복사합니다.
  2. 2
    아래에 앱 주소와 코드 입력앱 주소에는 `https://amy-brain-map.vercel.app`을 입력하고, 복사한 코드를 붙여 넣습니다.
  3. 3
    연결 후 전체 기록 동기화저장 뒤 팝업에서 Chrome 전체 기록 가져오기를 누르면 진행률이 표시됩니다.

Chrome 기록 연결

수집하는 정보는 URL·제목·방문 시각·방문 횟수입니다. 시크릿 모드 방문은 Chrome 방문 기록에 포함되지 않으며 이 확장 프로그램도 수집하지 않습니다. 페이지 본문은 이 확장 프로그램이 읽거나 전송하지 않습니다. 연결 코드는 한 번만 사용되며 10분 뒤 만료됩니다.
