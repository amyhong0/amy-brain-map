…방금 코끼리 떠올렸죠?

우리 뇌엔 ’하지 마‘라는 스위치가 없습니다.
”하지 마“를 이해하려면, 뇌는 그걸 먼저 떠올려야 하거든요.

그래서

· ”폰 보지 말자“ → 더 만지고
· ”야식 참자“ → 배달앱을 열고
· ”불안해하지 말자“ → 더 불안해집니다

그럼 어떻게??

· ”하지 마“ → ”하자“
· 피하고 싶은 것 → 향하고 싶은 것
· ”야식 참자“ → ”따뜻한 물 한 잔“
