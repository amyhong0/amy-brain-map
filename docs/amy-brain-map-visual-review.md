# Amy Brain Map 시각 검토 기록

## 2026-08-14 미리보기 결과

데스크톱 미리보기에서 Amy Brain Map의 새 헤더, 밝은 인지 캔버스, 3열 브레인 맵 구성, 대화형 질문 패널, 연결 상세 카드가 정상적으로 렌더링되었다. 보호 키 미연결 상태에서도 안내 카드와 빈 지도 상태가 명확하게 나타났으며, 서비스명은 브라우저 제목과 화면 헤더에 일관되게 표시되었다.

390×844 모바일 미리보기에서는 기존 DOM 순서 때문에 `Map Lens`가 히어로 패널보다 먼저 표시되는 것을 발견했다. 사용자에게 핵심 가치와 질문 경험이 먼저 드러나도록 메인 브레인 맵 컬럼을 모바일 1순위, 지도 렌즈를 2순위, 대화 패널을 3순위로 조정했다.

검토 기준은 UIUX Pro Max 디자인 시스템의 고대비 포커스, 44px 수준의 주요 조작 영역, 색상 이외의 텍스트 범례, 가시적 키보드 포커스, 모션 감소 환경 존중 원칙이다.
